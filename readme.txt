== Description ==

「波克wpAI自动化插件」是一个内置在 WordPress 后台的 AI Agent 插件。你用中文把想做的事说出来，它自己拆解步骤、调用工具、执行、汇报结果，危险操作前先请你确认。

本插件免费开源（GPL-2.0-or-later），作者 zhikanyeye。
项目主页：https://github.com/zhikanyeye/wp-auto-Master

= 核心能力 =

* 对话式管理：自然语言下达指令，Agent 自主规划、调用工具、执行、汇报
* 全站操作：文章/页面/媒体发布管理、主题与插件安装管理、文件与代码编辑、系统设置与维护
* 网页采集：探测页面结构、生成选择器规则、清洗正文、图片本地化、来源去重、定时批量采集
* 自学习记忆：内置向量记忆库，任务经验自动沉淀（情景/语义/程序三种记忆），相似任务自动检索复用
* 独立嵌入服务：记忆向量固定使用 BAAI/bge-m3，硅基流动 API Key 与主模型独立配置；未配置时自动使用关键词检索
* 高危确认：删除、覆盖、改库等危险操作执行前请求用户确认
* 完整审计：所有工具操作留痕，可追溯
* 定时任务：「每天备份数据库」「每周一发文」到点自动执行
* 多角色协作：创建能力角色（内容/生图/运维），多角色分工完成复杂任务
* 多模型支持：兼容 OpenAI 协议，内置 DeepSeek / 通义千问 / 智谱 / 腾讯混元等多家预设

= 网页采集说明 =

采集功能面向资讯站与内容聚合站，全部通过对话完成：探测结构 → 验证列表选择器 → 验证字段规则 → 单篇试跑 → 固化规则 → 批量执行 → 定时采集。

支持相对链接补全、懒加载图片修复、GBK 等非 UTF-8 页面解码、登录态 Cookie 采集，采集结果默认存草稿便于人工复核。

请仅采集你拥有版权或已获授权转载的内容，并遵守目标站点的 robots 协议与服务条款。

= 记忆向量化配置 =

进入「波克wpAI → 模型设置 → 记忆向量化」，填写硅基流动 API Key 并测试连接。模型固定为 BAAI/bge-m3，接口地址默认为 https://api.siliconflow.cn/v1。该配置与主模型 API Key 独立保存；没有嵌入 Key 时，记忆系统自动降级为中文关键词检索。

== Installation ==

1. 上传插件目录 bokeauto 到 /wp-content/plugins/ 并启用
2. 进入「波克wpAI → 模型设置」，选择服务商并填写 API Key
3. 没有 Key 可先启用「本地演示模式」体验完整流程
4. 保存后进入「波克wpAI → 对话」开始使用

采集功能需要 PHP 的 dom 与 mbstring 扩展；后台异步执行需要可用的 PHP CLI（不可用时自动降级为同步模式）。

== Frequently Asked Questions ==

= 需要付费吗？ =
插件免费开源。你需要自备大模型 API Key（DeepSeek、通义千问等）。

= 数据安全吗？ =
所有请求直接发送到你配置的模型服务商；工具操作均记录审计日志；高危操作需你确认。

= 采集来的内容会直接发布吗？ =
默认存为草稿，需要你复核后手动发布。也可在规则中显式设置为直接发布。

= 采集会不会有法律风险？ =
请只采集你拥有版权或已获授权转载的内容，并遵守目标站点的 robots 协议与服务条款。插件提供工具，合规使用责任在使用者。
